 # BASH Handbook
 
 ## Special notation

 Current directory
 > .

 Parent directory
 > ..

 Home directory 
 > ~

 ## Basics

 Print working directory: 
 > pwd

 List files and directories within a specified directory
 > ls

 Change current working directory
 > cd

 ## Shortcuts

 Autocomplete: Attempt to fill in the rest of the word you're typing.
 > Tab key
